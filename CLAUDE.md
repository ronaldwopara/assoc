# Claude Project Notes

## Motion Design Skill

When work involves UI animation, transitions, easing, timing, hover motion, enter/exit states, micro-interactions, or motion polish, use the local skill at:

`.claude/skills/motion-design-1.0.0/SKILL.md`

Load its required references before giving motion recommendations or editing animation code:

- `.claude/skills/motion-design-1.0.0/references/decision-tree.md`
- `.claude/skills/motion-design-1.0.0/references/easing-tokens.md`

The key rule from the skill: every animation needs a job. If the motion has no clear purpose, recommend no animation.
